# Text-to-Audio Converter

A Python application that converts English text into MP3 audio using the gTTS library.

## Technologies
- Python
- gTTS
- Google Colab
- IPython Audio

## Usage
Run the notebook, enter the desired text, and generate and play the audio.

## Output
Generated speech is saved as `tts.mp3`.
